# Overtone

A word roguelite. Every word carries a few overtones, which are plain meaning tags like HEAT,
COLD, NATURE, DANGER. You lay words in a row, and the game scores what each word does to the word
beside it. Two that share an overtone pay points. Two that mean opposite things pay multiplier.
Two with nothing in common stop the line dead.

The game never reads the word itself, only its overtones, so the decision is always about meaning
rather than spelling.

[Play it](https://playovertone.web.app). Nothing to install.

## How it plays

You hold seven words and lay two to five of them in a row. The game walks the row left to right
and scores each neighbouring pair:

- Alike: they share an overtone. 40 points for each one they share.
- Opposite: they carry an opposed pair, like HEAT against COLD. Plus 1 to the multiplier, which
  is worth far more.
- Nothing: the line stops there, and every word after it scores zero.

Each round also wants two overtones and sets a target. Every match you play is 55 points and half
a multiplier. Some patterns have names and pay extra, the way a flush does in poker. An overtone
that just paid rests for two plays and pays nothing until it wakes. Clear a round and the
Bookseller sells you a Lens, or hands back a line you played for you to keep.

Three plays and three discards a round, six rounds a run. Miss a target and the run is over.

`1`-`7` pick, `Enter` play, `D` discard, `Space` hurry the scoring, `Esc` close.

## Run it

```bash
git clone https://github.com/AdithyaMana/overtone.git && open overtone/index.html
```

No build step, no dependencies, no server. `index.html` is the whole game: engine, 249 word
lexicon, 30 Lenses, art and styles in one file. Playwright is a dev dependency and nothing else
is.

```bash
npm test          # engine, no browser, no network
npm run test:e2e  # browser, desktop and phone
npm run deploy    # stage public/ and push to Firebase
npm run balance   # simulate full runs: win rate, where runs die
```

165 engine tests and 378 browser tests. The engine tier loads the real `index.html` into a Node
VM, so it runs the code that ships rather than a copy of it.

Do not run `firebase deploy` on its own. It ships whatever is already in `public/`, which is a
stale build. `npm run deploy` rebuilds first. Hosted at https://playovertone.web.app.

|---|---|
| `index.html` | The game. Standalone, and the source of truth. |

| `art/CARDS.md` | All 249 cards with their overtones and icons. |
