# Card list — 249 words

Every word in the lexicon, with the overtones the scoring engine reads off it.

**Artwork drop-in.** Save an image as `art/<slug>.png` and the game uses it automatically;
any word without a file keeps its generated emblem, so you can do these in any order and
ship partway through. Recommended size **440×280** (11:7), PNG or WebP.

**Shared style prompt:** `flat vector game-card illustration, bold simple shapes, thick clean outlines, limited 4-colour palette, single centred subject, dark desaturated blue-slate background, no text, no lettering, landscape 11:7 crop`

> Note: words a player invents with the Interpreter can never have a file, so the
> generated emblem has to stay as the fallback.
